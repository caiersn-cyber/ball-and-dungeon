# 球与地下城 | Ball and Dungeon

一款基于 JavaScript、p5.js 与 p5.play 开发的二维迷宫冒险游戏，也是程序设计实践课程的团队作品。玩家控制小球探索地下城，在有限视野中寻找路线，躲避怪物和中心弹幕，抵达迷宫右下方的目标区域。

## 核心玩法

- **迷宫探索**：在 31 × 31 的网格地图中移动，墙体与地图边界限制通行。
- **有限视野与灯光**：根据玩家与采样点的距离绘制遮罩；到达灯的位置时扩大可见范围，并呈现闪烁效果。
- **中心弹幕**：迷宫中心周期性向 12 个方向发射弹幕，命中玩家时扣除生命值。
- **怪物威胁**：地图中设置移动怪物，与怪物相遇会触发失败。
- **传送机制**：通过地图中的传送点切换位置，辅助探索与路线规划。
- **胜负结算**：抵达目标区域即可通关；生命值耗尽或遭遇怪物时失败，结算界面显示本局用时。

## 操作说明

| 操作 | 按键 |
| --- | --- |
| 开始游戏 | 在开始画面按住鼠标，使小球落入地下城 |
| 向上移动 | W |
| 向左移动 | A |
| 向下移动 | S |
| 向右移动 | D |
| 重新开始 | F5 或刷新页面 |

游戏初始生命值为 12。建议使用带键盘的电脑浏览器进行体验。若键盘没有响应，请先点击游戏页面，并切换至英文输入状态。

## 本地运行

项目为静态网页，所需 JavaScript 库随源码保存在 `libraries/` 中，无需执行 npm 依赖安装或构建命令。

1. 下载或克隆仓库，使用 VS Code 打开游戏目录。
2. 安装 VS Code 的 **Live Server** 扩展。
3. 右键根目录下的 `index.html`，选择 **Open with Live Server**。
4. 在打开的浏览器页面中开始游戏。

请通过本地 HTTP 服务运行，并保留图片、音频与动画资源的原有相对路径。浏览器可能需要在鼠标交互后才允许播放声音。

项目维护者已完成本地运行检查，确认程序可以正常运行。

## 技术实现

| 模块 | 实现方式 |
| --- | --- |
| 页面与渲染 | HTML、CSS、JavaScript，使用 p5.js 绘制画布 |
| 地图表示 | 二维数组存储墙体与通路，每个网格对应 40 像素 |
| 角色移动 | 根据 WASD 输入更新网格坐标，移动前检查边界与目标格是否可通行 |
| 动画与精灵 | 使用 p5.play 加载动画、创建和绘制精灵 |
| 视野效果 | 计算玩家到采样点的距离，以不同大小的黑色圆点形成遮罩 |
| 弹幕运动 | 使用坐标平移、旋转及三角函数实现中心放射弹幕与碰撞距离检测 |
| 音频播放 | 使用 p5.sound 加载与播放音乐 |
| 用时显示 | 根据游戏循环计数换算显示用时，并在结算时停止计数 |

当前画布尺寸为 1240 × 1240，主要面向桌面端键盘操作。计时基于游戏循环计数，实际显示精度会受到运行帧率影响。
